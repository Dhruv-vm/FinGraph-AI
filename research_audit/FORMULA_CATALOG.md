## 1. Vector Semantic Similarity

### Formula:
$$\text{sim}_{\text{cos}}(\mathbf{q}, \mathbf{d}) = \frac{\mathbf{q} \cdot \mathbf{d}}{\|\mathbf{q}\|_2 \|\mathbf{d}\|_2} = \frac{\sum_{i=1}^{D} q_i d_i}{\sqrt{\sum_{i=1}^D q_i^2} \sqrt{\sum_{i=1}^D d_i^2}}$$

### Variables & Parameters:
- $\mathbf{q} \in \mathbb{R}^D$: Dense embedding of query text generated by encoder $\phi(q)$.
- $\mathbf{d} \in \mathbb{R}^D$: Dense embedding of document chunk text $\phi(d)$.
- $D = 384$: Embedding dimensionality (`sentence-transformers/all-MiniLM-L6-v2`).
- $\|\cdot\|_2$: Euclidean $L_2$ norm.
- Implementation: `src/retrieval/vector.py` via Qdrant `models.Distance.COSINE`.

## 2. Standard Reciprocal Rank Fusion (RRF)

### Formula:
$$\text{RRF}(d) = \sum_{m \in \mathcal{M}} \frac{w_m}{k + \text{rank}_m(d)}$$

### Variables & Parameters:
- $\mathcal{M} = \{\text{vector}, \text{graph}\}$: Set of retrieval modalities.
- $\text{rank}_m(d) \in \{1, 2, \dots, N_m\}$: Ordinal rank position of document $d$ within modality $m$'s retrieved set.
- $k \in \mathbb{R}^+$: Smoothing constant ($k=60$, standard Cormack et al. setting).
- $w_m \in [0, 1]$: Modality weight ($w_{\text{vector}} = 1.0, w_{\text{graph}} = 1.0$).
- Implementation: `src/retrieval/hybrid.py:reciprocal_rank_fusion()`.

## 3. Entity-Balanced Allocation & Quota Scoring

### Formal Definition:
For a comparative query requiring entity set $\mathcal{E}_Q = \{E_1, E_2, \dots, E_M\}$ with $|\mathcal{E}_Q| \ge 2$, let $\mathcal{C}$ denote candidate evidence pool sorted descending by $\text{RRF}(d)$.

$$\mathcal{A}(E_i) = \left\{ d \in \mathcal{C} \mid \text{matches}(d, E_i) \land \text{provenance\_verified}(d) \right\}$$

Quota assignment:
$$\mathcal{S}_{\text{alloc}} = \bigcup_{E_i \in \mathcal{E}_Q} \text{Top}\left(\mathcal{A}(E_i), \min(k_{\text{min}}, |\mathcal{A}(E_i)|)\right)$$
$$\mathcal{S}_{\text{remaining}} = \text{Top}\left(\mathcal{C} \setminus \mathcal{S}_{\text{alloc}}, K - |\mathcal{S}_{\text{alloc}}|\right)$$
$$\mathcal{S}_{\text{final}} = \mathcal{S}_{\text{alloc}} \cup \mathcal{S}_{\text{remaining}}$$

- $K = 8$: Top-K context budget.
- $k_{\text{min}} = 3$: Minimum reserved evidence quota per required entity.
- Implementation: `src/retrieval/hybrid.py:apply_entity_balanced_allocation()`.

## 4. Bitemporal Snapshot Validity & Availability Inequality

### Formula:
Given an inquiry timestamp $t_{\text{ref}}$, a knowledge graph entity $v$, edge $e$, or chunk $c$ is admissible if and only if:
$$\mathbb{I}_{\text{valid}}(c, t_{\text{ref}}) = \begin{cases} 1 & \text{if } t_{\text{available}}(c) \le t_{\text{ref}} \land \left(t_{\text{valid\_from}}(c) \le t_{\text{ref}} \le t_{\text{valid\_to}}(c)\right) \\ 0 & \text{otherwise} \end{cases}$$

For pure point-in-time snapshot gating:
$$t_{\text{available}}(c) \le t_{\text{as\_of}}$$
- Implementation: `src/data/graph/snapshot.py:is_available()`, `build_temporal_snapshot()`.

## 5. Future Evidence Infiltration Rate (FEIR)

### Formula:
$$\text{FEIR}(\mathcal{E}, t_{\text{ref}}) = \frac{\sum_{e \in \mathcal{E}} \mathbb{I}\left(t_{\text{available}}(e) > t_{\text{ref}}\right)}{|\mathcal{E}|}$$

### Boundary Conditions:
$$\text{FEIR} \in [0.0, 1.0], \quad \text{FEIR} = \text{None if } |\mathcal{E}| = 0 \text{ or } t_{\text{ref}} = \text{None}$$
- Implementation: `src/evaluation/temporal.py:calculate_feir()`.

## 6. Token-Level Evaluation Metrics

### Normalization Function:
$$\text{norm}(s) = \text{lowercase}\Big(\text{strip\_punct}\big(\text{strip\_articles}(s)\big)\Big)$$

### Token Precision, Recall, and F1:
Let $\mathcal{P} = \text{BagOfWords}(\text{norm}(\hat{y}))$ and $\mathcal{G} = \text{BagOfWords}(\text{norm}(y^*))$.
$$\text{Shared} = \sum_{w \in \mathcal{P} \cap \mathcal{G}} \min(\text{count}_{\mathcal{P}}(w), \text{count}_{\mathcal{G}}(w))$$
$$\text{Prec}_{\text{token}} = \frac{\text{Shared}}{|\mathcal{P}|}, \quad \text{Rec}_{\text{token}} = \frac{\text{Shared}}{|\mathcal{G}|}$$
$$\text{F1}_{\text{token}} = \begin{cases} \frac{2 \cdot \text{Prec}_{\text{token}} \cdot \text{Rec}_{\text{token}}}{\text{Prec}_{\text{token}} + \text{Rec}_{\text{token}}} & \text{if } \text{Prec} + \text{Rec} > 0 \\ 1.0 & \text{if } |\mathcal{P}| = 0 \land |\mathcal{G}| = 0 \\ 0.0 & \text{otherwise} \end{cases}$$

### Exact Match (EM):
$$\text{EM}(\hat{y}, y^*) = \mathbb{I}\left(\text{norm}(\hat{y}) = \text{norm}(y^*)\right)$$
- Implementation: `src/evaluation/qa.py:token_f1_score()`, `exact_match_score()`.

## 7. Refusal Confusion Matrix & Decision Accuracy

Let $\mathcal{Q} = \mathcal{Q}_{\text{ans}} \cup \mathcal{Q}_{\text{unans}}$:
- $TP$ (Correct Refusal): Refused when $q \in \mathcal{Q}_{\text{unans}}$.
- $FP$ (False Refusal): Refused when $q \in \mathcal{Q}_{\text{ans}}$.
- $FN$ (Hallucination): Answered when $q \in \mathcal{Q}_{\text{unans}}$.
- $TN$ (Correct Answer): Answered when $q \in \mathcal{Q}_{\text{ans}}$.

$$\text{Decision Accuracy} = \frac{TP + TN}{|\mathcal{Q}|} = \frac{14 + 45}{64} = \frac{59}{64} = 92.19\%$$
$$\text{Refusal Recall} = \frac{TP}{TP + FN} = \frac{14}{14 + 0} = 100.0\%$$
$$\text{Hallucination Rate} = \frac{FN}{|\mathcal{Q}_{\text{unans}}|} = \frac{0}{14} = 0.0\%$$
- Implementation: `src/evaluation/qa.py:RefusalMetrics`.

- $Y \in \{0, 1\}$: Binary 5-day return direction indicator $\mathbb{I}(R_{t+5} > 0)$.
- $\mathbf{x} \in \mathbb{R}^{19}$: Standardized feature vector (`MARKET + SEC V3`).
